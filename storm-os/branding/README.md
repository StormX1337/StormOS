# STORM OS branding

All artwork is original STORM OS artwork; no Microsoft logos or assets are used or modified.

| Asset | Use |
|---|---|
| `logos/storm-mark.png` | brand mark (512 px) |
| `logos/storm-logo.png`, `logos/storm-logo-dark.png` | mark + wordmark for dark / light backgrounds |
| `logos/StormOS-oem-logo.bmp` | OEM logo, Settings > System > About (120x120, 24-bit BMP) |
| `logos/StormOS-oobe-logo.png` | OEM logo during Windows OOBE (oobe.xml) |
| `wallpapers/storm-dark.jpg` / `storm-light.jpg` | 4K wallpapers (dark is the default) |
| `wallpapers/storm-lockscreen.jpg` | lock screen image |
| `icons/StormOS.ico` | application icon |

Colors: accent `#3FC1FF`, dark accent `#0B84C6`, background `#0F131B`, surface `#161C28`.
Regenerate with `python3 tools/generate-branding.py` (Pillow).
