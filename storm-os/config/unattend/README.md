# Answer file

The answer file is generated by `scripts/09-configure-oobe.ps1` (`New-StormUnattendXml`) and placed at
`Windows\Panther\unattend.xml` inside the image. It only sets the default theme in the `oobeSystem` pass.

`Test-StormUnattendSafety` rejects (build and validation fail): a `windowsPE` pass, disk configuration, product keys,
user accounts, passwords, automatic logon, skipped or pre-answered OOBE pages, setup commands and any requirement or
network bypass. Windows Setup therefore stays fully interactive: the user picks the disk, accepts the license,
signs in and makes the privacy choices.
